# Benchmarking Computational Methods for Senescent Cell Identification in Single-Cell RNA-seq Data

This repository contains the code, gene signatures, intermediate files, and analysis outputs accompanying the manuscript:

**Benchmarking of senescent cell identification algorithms across heterogeneous human scRNA-seq datasets**

The study presents a systematic comparative evaluation of computational methods for identifying and characterizing senescent cells using single-cell RNA sequencing (scRNA-seq) data.
